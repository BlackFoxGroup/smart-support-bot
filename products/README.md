# Products

This folder is empty on purpose in the public package.

Add your own products with Expert/Manager. Each product lives at:

```text
products/<product-id>/
├── catalog.json
├── ai_profile.json
└── media/          (optional screenshots)
```

`ai_profile.json` is created automatically when you save or activate a catalog.
Do not ship another vendor’s private catalogs in a public download.
